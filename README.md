# 🌐 Meu Portfólio

Bem-vindo ao meu portfólio! Este projeto foi desenvolvido com o objetivo de apresentar minhas habilidades, experiências, projetos e conhecimentos na área de desenvolvimento web.

## 📌 Sobre o projeto

O site é um portfólio pessoal, criado para mostrar um pouco sobre mim, minhas habilidades técnicas e os projetos que desenvolvi ao longo da minha jornada como desenvolvedor.

A proposta é oferecer uma interface moderna, intuitiva e responsiva, proporcionando uma boa experiência aos visitantes.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- **Sobre mim:** apresentação pessoal e trajetória profissional.
- **Habilidades:** demonstração das minhas principais competências técnicas.
- **Projetos:** exposição dos projetos desenvolvidos.
- **Contato:** formas de entrar em contato comigo.
- **Design responsivo:** adaptação para diferentes tamanhos de tela.
